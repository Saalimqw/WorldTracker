# ⬡ WorldTracker

**Global Intelligence Node & Event Horizon Telemetry**

WorldTracker is a real-time, autonomous crisis telemetry dashboard. It visualizes live seismic activity and simulated Open-Source Intelligence (OSINT) events on a highly interactive, procedural 3D WebGL globe. 

![WorldTracker](https://img.shields.io/badge/Status-Active-success)

## 🌟 Features

- **3D WebGL Globe:** High-performance procedural globe powered by `globe.gl` and Three.js, featuring translucent event markers and atmospheric glow.
- **Multi-Layer Intelligence:** Toggle between ~30 distinct telemetry layers including Seismic Activity, Military Bases, Nuclear Sites, Cyber Threats, Ship Traffic, and Orbital Surveillance.
- **OSINT Simulation Engine:** A Python-based background worker that continuously generates highly realistic, geographically accurate tactical briefings and threat intelligence.
- **Live Event Feed:** A real-time scrolling feed of incoming global events and anomalies.
- **AI-Powered Summaries:** Detailed, multi-sentence tactical updates, risk assessments, and SIGINT intercepts for every event.

## 🛠️ Tech Stack

**Frontend:**
- [Vite](https://vitejs.dev/) + TypeScript
- Vanilla CSS (Glassmorphism & Neon aesthetics)
- [Globe.gl](https://globe.gl/) (Three.js rendering engine)
- TopoJSON (110m resolution for ultra-fast country boundaries)

**Backend:**
- Python 3 + [Flask](https://flask.palletsprojects.com/)
- SQLite (WAL mode enabled for concurrent read/writes)
- Gunicorn (Production WSGI server)

## 🚀 Getting Started (Local Development)

### 1. Start the Backend API & Workers
The backend requires Python 3. It runs a Flask server alongside background tasks that scrape live USGS data and simulate OSINT events.

```bash
# Install Python dependencies
pip install -r requirements.txt

# Start the Flask API, the USGS Scraper, and the OSINT Simulator
bash start.sh
```
*Note: The backend runs on `http://localhost:3001`.*

### 2. Start the Frontend
The frontend is a Vite application.

```bash
cd frontend

# Install Node dependencies
npm install

# Start the Vite development server
npm run dev
```
*The Vite dev server will automatically proxy `/api` requests to your local Python backend.*

## ☁️ Deployment

WorldTracker is designed to be easily deployed across split infrastructure:

1. **Backend (Render.com / Railway):** Deploy the root folder as a Web Service. Use `bash start.sh` as your start command. The `requirements.txt` includes `gunicorn` for production serving.
2. **Frontend (Vercel / Netlify):** Change the fetch URL in `frontend/src/main.ts` to point to your live backend API. Then, deploy the `frontend/` folder directly to Vercel.
